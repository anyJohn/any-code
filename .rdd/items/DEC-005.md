# DEC-005: Memory 介入 = memory 工具主动调用（LLM 自主）

## 问题
Q-010 LLM 怎么介入 memory？

## 决策
新增 `save_memory` 工具注册进 ToolKit（`tools/functions/` + `schema.ts`），让 LLM 在 agentLoop 内自主决定是否调用、记什么内容、记到哪一层（项目/全局，见 DEC-006）。

## 理由
- 符合 any-code 是 agent 的定位：LLM 用工具表达"这事值得记"
- 无额外 LLM 调用与延迟——决策发生在现有推理循环内
- 不改 agentLoop 主体：工具经 ToolKit 注入，`core.ts` 推理逻辑不动（细化 DEC-002 的"例外"——加工具是注册进 allTools，不是编辑 core.ts）
- 去掉 `main.ts:234` 的无条件 `saveMemory`（改为由工具触发）

## 影响
- US-007 架构确定：新增工具 + 撤掉无条件 save
- domain/tools/ 新增一个 function + schema
- main.ts:234 调用点改语义
