# Raw Requirement: web 展示模型的 think block

## 来源
用户：web 展示模型的think block，带计时器，浅色小字体、可折叠、默认折叠

## 业务目标
- 展示模型的推理思考过程（reasoning_content / 类似字段），部分模型（如 DeepSeek R1）在思考阶段输出
- 样式：浅色小字体、可折叠、默认折叠
- 带计时器：从首段思考内容到达开始计时，到正式内容开始输出或 30s 后停止（防泄漏）

## 范围
- domain：callLLM 捕获 reasoning_content（delta 扩展字段），发 THINKING 事件
- core.ts：传 onThinkingDelta 回调
- type.ts：EventType 加 THINKING
- web：renderItems 累积 thinking 字段；新增 ThinkingBlock 组件（Collapsible + 计时器）
- TurnBlock：在 assistant text 前渲染 ThinkingBlock

## 实现记录
- domain/type.ts：EventType 加 THINKING = "Thinking"
- domain/llm.ts：callLLM 加 onThinkingDelta 参数；streamCall 捕获 delta.reasoning_content 发回调
- domain/core.ts：callLLM 调用传 onThinkingDelta → submit THINKING 事件（turnId 关联同回合）
- web/lib/sseEvents.ts：AgentEvent.type 加 "Thinking"
- web/lib/renderItems.ts：TurnItem 加 thinking 字段；groupByTurn 累积 Thinking 事件的 message
- web/components/ThinkingBlock.tsx：新组件，Collapsible 折叠，首段内容到达开始计时（requestAnimationFrame），finished 或 30s 停止
- web/components/ChatView.tsx：TurnBlock 在 assistant text 前渲染 ThinkingBlock（content=item.thinking, finished=!!item.assistant）；tagClass 加 Thinking
