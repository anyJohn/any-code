# Feature: Web 端用户体验提升（loading / 卡片 / 圆角 / 交互打磨）

## 现状（Impact，原始）
- **loading 三态合一**：拉 sessions 时 loading/empty/error 都显示「暂无会话」空态，用户分不清
- **fire-and-forget 无反馈**：newChat/resume/添加工作区 apiJson 返回 null 就静默 return，点击无 feedback
- **历史灌入前无 loading**：useAgent loadHistory 期间 events 为空 → 显示空状态
- **无 Skeleton 组件**：loading 都是纯文字
- **会话列表是 list 非 card**；助手消息无气泡包裹，与用户气泡视觉不对称
- **圆角三档混用**：sidebar rounded、主区 rounded-md、气泡 rounded-2xl
- **pending 只反映在输入区**，消息区无「思考中」indicator

## Stories（全已实现验证）

### US-004 loading 骨架化 ✅
sessions 列表/历史灌入/各 fetch 引入 Skeleton，区分 loading/empty/error 三态。
- `components/ui/skeleton.tsx`；page/AppSidebar/chat页/DirectoryPicker 三态渲染

### US-005 卡片化布局 + 圆角统一 ✅
会话列表卡片化（border + rounded + p-3），助手消息加气泡与用户气泡对称，圆角统一到 `--radius` 派生。

### US-006 思考中 indicator + 错误提示统一 ✅
pending 且本轮无 Assistant/Tool 事件 → 三点 typing indicator；apiJson null 静默分支补 text-destructive 错误提示。

### US-007 圆角卡片布局 + 可拖拽分割栏 ✅（FE-002 扩展）
两栏（sidebar + main）均为圆角卡片（`rounded-lg` border）浮于 `bg-muted/50` app 底色；中间三点 grab handle 可按住拖拽调左右宽度（`AppShell`，window mousemove/mouseup，clamp [200,480]，localStorage 持久化）。layout.tsx 保持 server（导出 metadata），交互抽到客户端 `AppShell`。

### US-008 侧栏 session 按钮常驻可见 ✅（FE-002 扩展）
删除/重命名按钮常驻行右侧（不再 hover/active 门控），缩小侧栏也不消失；title `flex-1 min-w-0 truncate` + `title` attr（超长省略、hover 全文）。
- **根因修**：Radix ScrollArea 的 Viewport 内层 `display:table` wrapper 撑 max-content（title 的 nowrap truncate 让 max-content=全文）→ 内容溢出 aside、按钮被裁。换原生 `overflow-y-auto` div（block 宽约束到 viewport）→ 行约束、title 缩、按钮入界。

### US-009 输入框圆角 + workspace 点名跳总览 + 新建对话移行首 ✅（FE-002 扩展）
- 对话输入栏外圈圆角容器（`rounded-lg` border + `focus-within:ring`），Input 去边框融入
- 点 workspace **名称** → 选中 + 展开 + 跳总览页（首页展示该工作区会话列表）；chevron 单独折叠
- 「新建对话」从 sessions 列表移到 workspace 行右侧 `+` 图标（点 + 新建对话）
- 清死代码 busy/setBusy（newChat/resume 已无网络往返）

### US-010 进入 session 自动滚到底展示最新 ✅（FE-002 扩展）
- ChatView `useLayoutEffect` + `didInit` ref：首次历史灌入**强制滚到底**（之前 nearBottom 逻辑在长历史下不滚、停在顶部看老消息）
- chat 页 ChatView 加 `key={sessionId}`：换会话重挂载 → 历史刷新 + didInit 重置，每次进入都滚底（顺带修了 latent bug：换会话不刷新历史）
- `useLayoutEffect` 在 paint 前滚，避免闪顶
