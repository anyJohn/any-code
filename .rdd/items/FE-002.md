# Feature: Web 端用户体验提升（loading / 卡片 / 圆角）

## 现状（Impact）
- **loading 三态合一**：拉 sessions 时（`page.tsx:33-36`、`AppSidebar.tsx:51-59`）loading/empty/error 都显示「暂无会话」空态，用户分不清
- **fire-and-forget 无反馈**：`newChat`/`resume`/添加工作区（`AppSidebar.tsx:74,82`、`page.tsx:43,53`、`AppTopbar.tsx:42`）apiJson 返回 null 就静默 return，点击无任何 feedback
- **历史灌入前无 loading**：`useAgent` loadHistory 期间 `events` 为空 → 显示空状态（`ChatView.tsx:255-258`）
- **无 Skeleton 组件**：现有 loading 都是纯文字「加载中…」；需 `npx shadcn add skeleton` 或手写 `animate-pulse`
- **会话列表是 list 非 card**（`page.tsx:95-100`、`AppSidebar.tsx:128-145`）；助手消息无气泡/卡片包裹，与用户气泡（`rounded-2xl`）视觉不对称
- **圆角三档混用**：sidebar 用 `rounded`、主区 `rounded-md`、气泡 `rounded-2xl`；`--radius` 变量在 `globals.css:75` 改一处可全局派生
- **pending 只反映在输入区**（按钮变「停止」+ 输入框 disabled），消息区无「思考中」indicator

## Stories

### US-004 loading 骨架化
为 sessions 列表、历史灌入、各 fetch 引入 Skeleton / spinner，区分 loading / empty / error 三态。
- 引入 `components/ui/skeleton.tsx`（shadcn add）
- 改造点：`page.tsx:95-103`、`AppSidebar.tsx:128-145`、`chat/[id]/page.tsx:75-77`、`ChatView.tsx:255-258`、`DirectoryPicker.tsx:93-94`

### US-005 卡片化布局 + 圆角统一
会话列表卡片化（Card + border + p-3 + rounded-xl），圆角统一到 `--radius` 派生变量。
- 待决策：卡片化范围（仅列表 / 含消息气泡 / 全布局）
- sidebar 现用 `rounded`+`text-xs` 紧凑布局，卡片化会增宽，需调 ScrollArea 缩进

### US-006 思考中 indicator + 错误提示统一
pending 时消息区渲染 typing indicator；apiJson null 的静默分支补错误提示（复用 DirectoryPicker 的 `text-destructive` 模式）。

## Open Questions（本 Feature）
- Q-006 loading 范围（全场景 / subset）
- Q-007 卡片化范围（仅会话列表 / 含消息气泡 / 全布局）
- Q-008 是否要「思考中」typing indicator
