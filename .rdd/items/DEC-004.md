# DEC-004: 卡片化范围 = 会话列表 + 消息气泡

## 问题
Q-007 卡片化布局覆盖到哪？

## 决策
- 会话列表（侧栏 + 主区）卡片化：Card + border + p-3 + rounded-xl
- 消息气泡对称化：助手消息加气泡/卡片包裹（现状走 MarkdownRenderer 无包裹，与用户气泡 `rounded-2xl` 不对称）
- 圆角统一到 `--radius` 派生变量（`globals.css:75` 改一处全局生效）
- 不做顶栏/空状态/输入区全布局重排

## 理由
视觉收益最大（列表 + 气泡是用户最常看的两处），工作量可控。全布局接近重做 UI，不值。
