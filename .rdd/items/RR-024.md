# Raw Requirement: 重构 AnyCode 事件系统（报错/系统事件 + 用户/LLM 消息架构）

## 来源
开发者自驱。error-persistence 实现中（commit 01fe3e4）暴露事件模型根因缺陷：`AgentEvent` 的 `data?:any` + domain 抛 raw Error → 读写 shape 分叉、reload 靠 `messagesToEvents` 反推 + `mergeEvents` 内容匹配定位、重建有损（deltas/usage/progress 丢）。调研 pi / opencode / hermes / deepseek-harness 后立项重构。**产品未上线，breaking change 可接受。**

## 业务目标
1. **错误是一等、可序列化的事件 variant**：domain 发出即 plain object，live==persisted by construction，消灭 replacer / shape 分叉 / 定位 hack。
2. **durable 事件日志 = reload 真值**：退役 `messagesToEvents`/`mergeEvents`，reload 重放日志，定位 by construction。
3. **messages 仍为 LLM context 真值**：callLLM + compact 不变。
4. **错误分终态(Error)/非终态(Warning)**：修"压缩失败误终止 run"的 latent bug，对齐 opencode `tool-error`(非终态)/`provider-error`(终态)。

## 需求描述
`AgentEvent` 从 `EventType enum + data?:any` 改为可序列化 discriminated union（error 为一等 variant，`ErrorPayload`）；持久化 durable 事件日志（User/Iteration/Thinking/Assistant/Tool/Error/Warning/Stopped/Done/Compact）作 reload UI 真值，ephemeral（deltas/progress/ToolStart）live-only；messages 保持 LLM 真值。分阶段：P1 可序列化 Error variant + 终态/非终态拆分；P2 durable 日志作 UI 真值、退役 `messagesToEvents`/`mergeEvents`；P3 全量 typed union；P4（可选远期）pi 风格 transcript/context 分层。

## 范围
- **在范围内**：domain `type.ts`/`eventStream.ts`/`core.ts`/`main.ts`/`tools/*` 事件 emit、server SSE 序列化 + 持久化、web 事件类型 + 渲染 + reload 重放、相关测试。
- **不在范围内**：多协议（OpenAI-only by design）、插件化/DI（守 `SessionStore` 接口不泛化）、auto-update、桌面端。
- **场景判定**：**场景 B（整体替换）**——事件模型 + reload 路径重写，调用方（18 emit 站点 + web 渲染 + `/history` shape）变更，旧路径（`messagesToEvents`/`mergeEvents`/adapter-replacer/Error-as-terminal）删除或标 superseded。违反 SPEC-028 I-003（"SSE 事件流协议不变"）——产品未上线，I-003 superseded。
