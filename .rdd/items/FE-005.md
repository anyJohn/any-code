## Stories（Lite 内联，不拆 US）

### US-A agentLoop 控制流可测 ✅ 待实现
`agentLoop`（domain/src/core.ts）的核心路径有回归测试：有 tool_calls→执行→回灌→循环；无 tool_calls→返回 result；`signal.aborted`→stopped；达 maxIter→截断。mock callLLM 返回固定响应驱动。

### US-B toolCall 派发可测 ✅ 待实现
`toolCall`（domain/src/tools/toolCall.ts）：按 function name 派发到 handler、提交 TOOL 事件、未知工具/未注册工具处理。

### US-C task 串行与中断可测 ✅ 待实现
`initProcessor` / `executeTask`（domain/src/main.ts）：task$ 经 concatMap 串行、stop$ 中断（takeUntil）、pendingTasks$ 增减、session 延迟创建（ensureSession）。

### US-D session store 可测 ✅ 待实现
`session/`：append/load/findKey/findSession、entries↔Session 转换。用临时目录作 fs mock。

### US-E EventStream per-agent 隔离可测 ✅ 待实现
`eventStream.ts`：submit→event$/history$、多实例不串流、destroy 后清理。
