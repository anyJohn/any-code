# Feature: 配置文件 + 多 provider + 流式开关（domain 基础）

## 现状（Impact）
- 配置仅靠 .env（OPENAI_API_KEY/BASE_URL/MODEL），Config 类读 env，单一 provider，无运行时切换
- callLLM 流式（FE-007）已默认 stream:true，无开关
- 与 P1 "多 provider + 运行时模型切换"重叠，本 FE 把它落地 + 加配置文件 + 流式开关

## Stories（Lite 内联）
- US-A 配置文件：定义配置文件（格式/位置待决），含多 provider 列表 + 默认 provider + 流式开关
- US-B 多 provider：Config 支持命名 provider（各带 apiKey/baseUrl/model），运行时按名切换
- US-C 流式开关：配置项控制 callLLM stream:true/false
- US-D 兼容：.env 仍作为后备（无配置文件时退回 .env 单 provider）

## Open Questions（全已决策 → DEC-024..027，见 SPEC-008）
- Q-1 格式 → YAML (.anycode/config.yaml) + js-yaml (DEC-024)
- Q-2 provider 形态 → 命名 provider map (DEC-025)
- Q-3 切换 → default + 热更新切 (DEC-026)
- Q-4 流式开关 → provider 粒度（各 provider 自带 streaming）(DEC-027)

  - `core.ts`：agentLoop 传 `ctx.llm` 给 callLLM
  - `main.ts`：AnyAgent `initConfig()` + executeTask 的 ctx.llm + `reloadConfig()`/`getCurrentProvider()`（供 FE-009 web 触发、FE-012 读状态）
