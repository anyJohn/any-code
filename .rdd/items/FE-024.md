# FE: 后台运行与多 agent 并行

## 描述

server 侧托管运行中的 agent：agent 存活期与客户端连接解耦（= server 进程存活期）；事件流带序号可重挂续传；停止改为显式 API；会话列表显示运行状态并跨会话聚合权限确认；并发上限可配；server 退出统一清理。

## 拆解（单 Feature，无 US 拆分）

- domain：事件序号 / 终态销毁时序微调（尽量不加复杂度）
- server：AgentManager（托管表 + since 续传 + stop + 状态查询 + 退出清理 + 并发闸）
- web：会话列表状态徽标 + pending ask 跨会话提醒 + 断线重挂

## 依赖

- 复用：AR-18 MCP 池（多 agent 共享连接）、AR-3 交互通道（pendingInteractions）、FR-14 终态事件
- 被依赖：FR-21（重挂基建复用）、AR-23（重建一致性）
