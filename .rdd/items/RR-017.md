# Raw Requirement: maxOutputTokens 配置（同 contextWindow 模式）

## 来源
用户：增加 max output tokens 配置，配置大模型最大输出。同 contextWindow：先从接口拉取再读本地配置，两者取最小。

## 业务目标
- LlmProvider 加 maxOutputTokens（optional）；探测 GET /models 的 max_output_tokens；与用户配置取 min；callLLM payload.max_tokens = resolved
- 呼应 RR-016 deferred：当前模型 输出截断在 ~4096——给用户显式配置 max_tokens 的杠杆

## 决策（Human 决，同 contextWindow 模式）
- 探测 + 用户配置取 min（DEC-081）
- 全空 → undefined（不传 max_tokens，用 provider 默认，不瞎设）（DEC-082）
- 与 contextWindow 共享 detect 缓存（一次 /models 取两字段）（DEC-083）

## 验证结果（SPEC-023）
- AC-001 resolveMaxOutputTokens 取 min / 全空→undefined：config.test ✓
- AC-002 detectMaxOutputTokens：config.detect.test ✓（max_output_tokens/max_completion_tokens 取值；与 contextWindow 共享缓存一次 list）
- AC-003 callLLM payload.max_tokens = resolved（有则传，undefined 不传）：llm.test ✓
- AC-004 settings 表单 maxOutputTokens 输入（空=auto）+ 保留：build ✓
- 真 run：当前模型 → contextWindow=1000000（dashscope 返回）、maxOutputTokens=undefined（未探测/未配→不传）✓；用户在 /settings 配 16384 → resolved 16384 → 传 max_tokens
