# Feature: 流式输出（token 级）

## 现状（Impact）
- `callLLM`（domain/src/llm.ts）非流式：整段返回后才发 `ASSISTANT` 事件，用户等完整回复才看到内容
- 前置已具备：Web（`useAgent.ts` + `ChatView`）与 TUI 已做 SSE fetch-streaming UI 侧，只差 LLM 侧 token 级流式
- `agentLoop`（core.ts）当前：`callLLM` 返回完整 msg → push messages → 发 `ASSISTANT` 事件 → 处理 tool_calls。流式需改为边收 chunk 边发增量、流结束才定稿

## Stories（Lite 内联，不拆 US）

### US-A callLLM 流式化 ✅ 待实现
`callLLM` 改 `stream: true`，消费 `ChatCompletionChunk` 流，累积成完整 assistant message（content + tool_calls 按 index 拼装），返回累积后的 message。AbortSignal 真打断流式生成。

### US-B agentLoop 发增量事件 ✅ 待实现
`agentLoop` 边收 chunk 边发增量事件（ASSISTANT_DELTA），流结束发整段定稿事件（ASSISTANT），再处理 tool_calls。abort 时截断已生成内容为一条 assistant message。

### US-C 事件类型 + 持久化 ✅ 待实现
新增/复用事件类型承载增量；增量是实时态不入盘，整段定稿才落盘；历史回放（`messagesToEvents`）只重建整段，不回放 delta。

### US-D Web 增量渲染 ✅ 待实现
`useAgent` 处理增量事件，`ChatView` 边收边渲（追加到当前 assistant bubble），定稿时确认。

### US-E TUI 增量渲染 ✅ 待实现
Ink `<Static>` 对增量的渲染（追加 vs 重渲最后一帧）。

## Open Questions（全已决策 → DEC-020..023，见 SPEC-007）
- Q-1 事件类型 → 新增 ASSISTANT_DELTA + ASSISTANT 双事件 (DEC-020)
- Q-2 落盘 → 整条写，delta 不入盘 (DEC-021)
- Q-3 工具调用 → 按 index 拼装 (DEC-022)
- Q-4 UI 范围 → Web + TUI 都做 (DEC-023)

（非 blocking，SPEC-007 内标 inferred：abort 流式语义——已有 AbortSignal 穿透，验证 stream 取消即可；TUI `<Static>` 重渲细节随实现）

## 实现记录
- domain：
  - `type.ts` 新增 `EventType.ASSISTANT_DELTA`（"AssistantDelta"）

  - `core.ts` agentLoop：传 onDelta → 发 ASSISTANT_DELTA（实时不入盘）；流结束发 ASSISTANT 整段 + onMessage 落盘整条；abort 截断时 partial 落盘定稿 + 返回 [stopped]
