# Feature: Web 状态/用量监控面板

## 现状（Impact）
- Web 对话页无上下文余量、当前模型、skill 数、MCP 连接状态的可观测展示
- domain 未暴露这些状态供 web 读

## Stories（Lite 内联）
- US-A 上下文余量：展示当前会话 token 用量 / 余量（domain 估算）
- US-B 当前模型：展示当前 provider/model（依赖 FE-008）
- US-C skill 状态：展示已加载 skill 数 + 列表（从 .anycode/skills/）
- US-D MCP 状态：展示 MCP server 连接状态（连上/失败/工具数，依赖 FE-006）
- US-E 展示位置：对话页常驻条/抽屉/侧栏底部

## Open Questions（全已决策 → DEC-033..036，见 SPEC-012）
- Q-1 token 用量 → 真实 API usage（callLLM 捕获，对齐 claude-hud）(DEC-033)
- Q-2 状态暴露 → USAGE 事件 SSE 内联 + GET /api/status 静态 (DEC-034)
- Q-3 展示形态 → 聊天框底部状态条 (DEC-035)
- Q-4 MCP 粒度 → 仅 configured 列表 (DEC-036)

## 实现记录
- domain：
  - `type.ts`：新增 `EventType.USAGE` + `LlmUsage` 类型
  - `config.ts`：LlmProvider 加 `contextWindow`（缺省 128000）；normalize/envFallback 设
  - `llm.ts`：callLLM 捕获 usage（非流式 `resp.usage`；流式 `stream_options.include_usage` 末片 `chunk.usage`），附在返回 message 上
  - `core.ts`：agentLoop 每轮 callLLM 后发 USAGE 事件 `{prompt_tokens, completion_tokens, contextWindow, turnId}`（实时态，不入 messages 数组）
- web：
  - `lib/sseEvents.ts`：AgentEvent.type 加 "Usage" + `UsageData` 接口
  - `lib/renderItems.ts`：groupByTurn 对 Usage 静默跳过（不打断回合）
  - `app/api/workspaces/[projectKey]/status/route.ts`：GET 返 {provider, model, contextWindow, skillCount, skillNames, mcpServers:[{name,type}]}（configured mcp，无活探测）
  - `components/ChatView.tsx`：底部 StatusBar（model + 用量条 prompt/contextWindow + skill 数 + mcp 数；GET /status 拉静态 + 扫 events 最新 Usage 实时更新）；projectKey 改 prop（页面传，不直接用 redux）
  - `app/chat/[sessionId]/page.tsx`：ready 加 projectKey，传给 ChatView
- 测试：config.test 加 contextWindow（AC-003）；core.streaming 加 USAGE 事件（AC-008）
- 验证：domain tsc 0 + 31/31 + build；web tsc 干净（除既有 providers jest-dom 错）+ 53/54 无新回归
- deferred：usage 持久化+回放（v1 实时态，reload 由首轮流补）、model→contextWindow 自动识别、用量条阈值配色、MCP 活探测
