# Feature: 内置能力体系（abilities 注册器 + 四层技能 + 目录注入 + AGENTS.md 规则）

## 交付物

1. **abilities 注册器**（domain `abilities.ts` + `builtin.ts`）：`Ability = {name, kind:"skill"|"mcp", description, ...}`；注册器层内同名 fail-fast；配置决议 `enabled = config.abilities?.[name]?.enabled ?? false`（缺省关，随包默认 config 开，不可删）。
2. **四层技能**（`skill.ts` 重写）：来源序 项目 `.anycode/skills/*.md` > 全局 `~/.anycode/skills/*.md` > `.agents` `~/.agents/skills/*.md` > 内置（abilities kind:skill）；同名后层覆盖 + warning。
3. **目录注入 + skill 工具**：system prompt 只注入目录（name+description，预算截断）；新增 `skill` 工具按需返回全文 `<skill_content>`；`reloadConfig` 热生效。
4. **AGENTS.md 规则**（`rule.ts` 重写）：退役 `.anycode/rules/` 多文件；规则 = `~/.anycode/AGENTS.md` + `workspaceDir/AGENTS.md` + `.agents/AGENTS.md` additive 注入（含顺序/去重）；破坏性不兼容。
5. **MCP 内置并入**（`mcp.ts`）：kind:mcp abilities 并入连接集；`enabled:false` 剔除；同名整条覆盖；内置连接器 bundled stdio server。
6. **Settings 能力面板**：网络"内置能力"展示注册器的 name/description + 开关（不可删）。
7. **默认配置**：config.example.yaml 与默认配置预置 abilities。

## 依赖

- SPEC 批准后拆 Task（TK）逐文件实现。
- 内置能力清单与连接器实现形态待 Q 决（见 RR-025 尾部）。
