# Feature: agent 连接持有，去 AgentPool（目标 C）

## 现状（要被替换，标 superseded）
- AgentPool：`Map<agentId, AnyAgent>` + TTL 30min + globalThis hack。任务跨 SSE 重连存活（违背"关页面=停"认知）
- 三路 route：POST /messages（起任务 202）+ GET /events（SSE）+ POST /stop，靠 pool 桥接
- URL `/chat/{agentId}`；agentId 无盘后盾 → 重启/过期 → "已失效"（历史也读不到）
- 历史走 pool（getAgent→getSession→messages），过度耦合

## 目标行为
- agent 生命周期 = 一个 HTTP 连接（task 级，用完即弃）
- 关页面/断连接 = 任务停（abort 在途 LLM + destroy）
- URL `/chat/{sessionId}`；sessionId 有盘后盾，随时 resume
- 历史直读盘（`SessionService.list/load`），不过 agent
- 新对话：首条消息时 ensureSession 创建 session，sessionId 经响应头回前端，前端 replaceState

## Stories
### US-010 服务端 /run + /history route（替换三路 + pool）
- POST /api/sessions/:sessionId/run {task, workspacePath} → SSE 流：create→订阅→submit→泵→终态收尾→destroy；abort=stop+destroy
- POST /api/sessions/run {task, workspacePath}（新对话）→ ensureSession + X-Session-Id 头
- GET /api/sessions/:sessionId/history → 直读盘
- 删 agentPool + agents/* route

### US-011 客户端 useAgent 改 fetch-stream + sessionId URL
- useAgent：EventSource → fetch+ReadableStream（POST /run 流响应解析 `data: ...\n\n`）
- stop = abort fetch（AbortController）
- history 单独 GET /sessions/:id/history
- chat 页 URL /chat/[sessionId]；探测改 history 直读（无"已失效"）
- AppSidebar resume/newChat + page.tsx 走 sessionId

### US-012 domain 微调（可选）：destroy abort 在途 LLM
- main.ts destroy() 加 `this.abortController?.abort()`——使"关连接=真停"语义闭合
