# DEC-008: 桌面 UI 加载 = loadURL（同源），refine DEC-007 的 loadFile

## 问题
DEC-007 设想桌面端"Electron `loadFile` 静态 dist + spawn hono sidecar"。但 `loadFile` 加载的 SPA 是 `file://` origin，其 `fetch` 到 `http://127.0.0.1:<port>`（sidecar API）会撞 CORS（`file://` origin 不能直接 fetch `http://localhost`，需关 `webSecurity` 或给 server 加 CORS 头——别扭且偏离范式）。

## 决策
桌面 UI 用 **`BrowserWindow.loadURL('http://127.0.0.1:<port>')`**：server（嵌入主进程，见 SPEC-029 C-001）同时 serve dist + API，**同源、无 CORS、100% 复用 web 流**（只换"窗口"替"浏览器"）。refine DEC-007 的 `loadFile` → `loadURL`。

## 理由
- 同源免 CORS，不关 `webSecurity`（安全）。
- 100% 复用现有 web 流（server serve dist+API 已验证，AC-001 hono 一体 serve）。
- DEC-007 的 `loadFile` 是未来设想、未实测 CORS；桌面正式立项（RR-023）时修正。
