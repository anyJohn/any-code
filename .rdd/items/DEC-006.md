# DEC-006: Memory 分层 = 两层独立

## 问题
Q-011 workspace 与全局 memory 怎么分？

## 决策
- 项目级：`<rootPath>/.anycode/memory.md`（现状保持）
- 全局级：`~/.anycode/memory.md`（新增，与 REGISTRY_DIR `workspace.ts:29` 同目录）
- 两层独立：各管各的，项目级不写全局、全局不被项目写
- `save_memory` 工具带 `scope: "project" | "global"` 参数，LLM 自选层级

## 理由
最简满足"workspace 与全局划分"诉求，写入边界清晰（无跨写）。跨 workspace 共享偏好（全局可被项目写）将来按需再开。

## 影响
- US-008 架构确定：加全局路径常量 + save/loadMemory 分层签名
- workspace.ts 加 `globalMemoryPath()` 配合 `workspaceConfigDir()`
- loadMemory 注入系统提示词时合并两层（全局 + 项目）
- 兼容旧项目级 memory.md（格式不变）
