# Feature: 端到端安装（Win+Linux）

## 现状（Impact）
- 无 `build/` 目录、无安装脚本、无一行安装命令——全新基建。
- `bash.ts`：`spawn(cmd,{shell:true})`，Windows 走 cmd.exe，LLM 的 ls/grep/&& 会失败（Windows agent bash 不可用）。
- TUI `bin: anycode` 存在但 TUI 不完善——不作入口，启动器另起。
- web 只验过 `next dev`，prod（next build+start）端到端未验。
- ripgrep 仅 pin linux-x64；根 package.json 无 packageManager。

## Stories（Lite 内联）
- US-A 安装器骨架：build/install.sh（Linux）+ install.ps1（Windows，一行 iwr|iex）+ install.bat（cmd 薄 shim→ps1）+ versions.env（锁 NODE_VERSION）+ README（一行命令）。
- US-B 私有 provision node：下载 nodejs.org 平台包到 ~/.anycode/runtime/node，corepack 激活 pnpm（不碰系统、不要 sudo）。
- US-C 拉仓库 zip：codeload archive zip（不依赖 git）解压到 ~/.anycode/app。
- US-D 构建：pnpm install --frozen-lockfile + pnpm --filter @anycode/web build（next build → web/.next）。
- US-E 注册命令：Linux 写 ~/.anycode/bin/anycode shim + patch .bashrc/.zshrc；Windows anycode.bat + setx User PATH。
- US-F 启动器：launcher.sh/launcher.bat——私有 node 起 next start（127.0.0.1，3000 默认/占用自增）+ 开浏览器 + 前台（Ctrl+C 杀）。
- US-G Windows agent bash：bash.ts 改显式 spawn(binary,["-c",cmd])；resolveShell（unix /bin/sh、win bash.exe via ANYCODE_GIT_BASH_PATH/系统 Git 回退）；toMsysCwd（C:\Users→/c/Users）。安装器下 PortableGit 到 ~/.anycode/runtime/portablegit + setx ANYCODE_GIT_BASH_PATH。
- US-H 配套小改：domain/package.json 加 @vscode/ripgrep-win32-x64 optionalDep；根 package.json 加 packageManager（corepack 锁 pnpm）；下载校验 sha256。
