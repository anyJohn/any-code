# DEC-001: sessionId 是 session 真正主键，agentId 是内存路由 key

## 问题
web 路由 `[id]` 用的是 agentId 还是 sessionId？删除/编辑 route 应以什么为路径参数？

## 决策
- `sessionId`（`session.ts:50` randomUUID）是磁盘文件名与列表主键
- `agentId`（`agentPool.ts:30` randomUUID）只是内存池 key，与 sessionId 解耦
- 新增 session 管理路由走 `/api/workspaces/[projectKey]/sessions/[sessionId]`，直接 `new SessionService()` 操作，不碰 agentPool

## 理由
现状代码确认（`[id]/route.ts:22` 把 sessionId 暴露在 agent 元信息里）。删除/编辑是磁盘操作，不应经内存 agent。
