# Feature: Web 配置面板 + 热更新

## 现状（Impact）
- 无 Web 配置界面，改 provider/model 得手改 .env 重启
- FE-008 落地配置文件后，本 FE 让 Web 能查看/修改配置并热更新（不重启）

## Stories（Lite 内联）
- US-A 配置面板：Web 页面查看当前配置（providers、默认、流式开关等）
- US-B 编辑保存：Web 改配置 → 写回配置文件
- US-C 热更新：保存后 agent 即时生效（切 provider/model、开关流式）无需重启
- US-D MCP 配置：MCP server 配置改动触发连接重建（FE-006 的 cleanup + 重连）

## Open Questions（全已决策 → DEC-029..032，见 SPEC-009）
- Q-1 入口 → 独立 /settings 页，侧栏底部入口 (DEC-029)
- Q-2 热更新范围 → MCP 配置收敛进 config.yaml 的 mcp 段（mcp.json 废弃），下次 /run 自动重连 (DEC-030)
- Q-3 写回 → GET/POST /api/config，写文件 + 校验 (DEC-031)
- Q-4 apiKey → GET 脱敏，POST 空值=保留原值 (DEC-032)

## 实现记录
- domain：
  - `config.ts`：ConfigShape 加 `mcp` 段 + 导出；Config 解析 `mcpServers`；新增 `Config.save(workspace, data)`（校验 providers/default/mcp type + js-yaml dump 写回）+ 导出 `maskApiKey`；reload 补 mcpServers；index.ts 导出 config
  - `mcp.ts`：`loadMcpTools(mcpServers)` 改收 Config.mcpServers（去 mcp.json 读取）；导出 `McpServerConfig` 类型
  - `main.ts`：initMcp 用 `this.config.mcpServers`
- web：
  - `app/api/workspaces/[projectKey]/config/route.ts`：GET 读 config（apiKey 脱敏，无文件返空骨架）；POST 写 config（校验 + 空 apiKey 保留原值）
  - `app/settings/page.tsx`：配置编辑页（providers/default/streaming/mcp 表单，apiKey 留空=不改+脱敏提示，保存反馈）
  - `components/AppSidebar.tsx`：底部常驻"设置"入口 → /settings
- config.example.yaml：加 mcp 段模板
- 测试：config.test 加 mcp 段解析（AC-001b）；mcp.test 改传 servers（AC-002）
- 验证：domain tsc 0 + 29/29 + build；web tsc 干净（除既有 providers jest-dom 错）+ 无新回归
- 注释清理：去掉"不再X/废弃/改由"等历史性注释（含 eventStream/memory/toolCall/sseEvents/AppSidebar/core/tools/index 等既有 + 本 FE 新写的），规则存记忆
