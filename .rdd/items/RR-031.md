# RR-031: Server 远程就绪（API key 鉴权 + 绑定可配 + web 远程连接）

## 业务目标

server/web 已解耦（HTTP/SSE 契约 + AgentManager 连接解耦重挂），具备远程化地基。本需求让 server 可安全暴露到局域网/远程：API key 鉴权 + 绑定可配，web 可连远程 server。移动壳（Capacitor 等）为后续独立条目。

## 用户决策（2026-09-16）

- 安全模型：**API key**，不做复杂配对；key 支持创建/删除（设置页管理，存 config.yaml）。
- 立场：缺省仍绑 127.0.0.1（本地立场不变）；远程是显式 opt-in（配 key + 改绑定）。
- Electron 不支持安卓——移动壳（Capacitor 包 web/dist）为后续条目，本条目交付 server/web 远程能力。

## 范围

- config：`auth.apiKeys` + `server.hostname`（缺省 127.0.0.1）
- server：hono 中间件鉴权（Bearer / X-API-Key，key 非空才启用）；hostname 可配
- web：设置页「远程连接」（server URL + API key，localStorage），api 层统一 base + header
- 桌面版/launcher 不变（本地路径不受影响）
