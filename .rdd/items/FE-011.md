# Feature: Web @file 引用文件

## 现状（Impact）
- Web 输入框无法引用文件，用户得手敲路径让 agent read；无 @ 触发的文件选择

## Stories（Lite 内联）
- US-A 触发：输入框 "@" → 弹出文件选择（workspace 内文件 autocomplete）
- US-B 选择：模糊匹配文件路径，选中插入为 @path chip
- US-C 注入：引用的文件如何进 context（全文注入 vs 只路径让 agent read）待决
- US-D 多引用：支持多个 @file，提交时一并处理

## Open Questions（blocking，待批量决）
- Q-1 注入策略：文件全文进 user message / 只注入路径让 agent 调 read / 注入前 N 行？
- Q-2 文件发现：workspace 全扫 vs 按目录浏览 vs glob 模式？大文件/二进制怎么拒？
- Q-3 路径基准：相对 workspace root？绝对？
- Q-4 chip 形态：@path 可删？展示文件名 vs 全路径？
