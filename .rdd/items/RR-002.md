# Raw Requirement: 目标 C —— agent 连接持有，去 AgentPool

## 来源
对话推演：ChatGPT/Gemini 网页端"关页面=任务停"是用户认知；当前 AgentPool 让任务跨 SSE 重连存活，违背该认知且带来"已失效"/TTL/globalThis 黑魔法/缓存一致性债/不可横向扩容。用户定目标 C：连接持有 agent，无 pool。

## 业务目标
- 行为符合用户认知：关页面 = 任务停（不后台偷偷跑）
- 删掉 AgentPool 整个失败类：agentId、"已失效"、TTL reaper、globalThis hack、内存 idle 占用、横向扩容阻碍
- 历史访问与活任务解耦：历史直读盘，不过 pool

## 范围
- **web 层**：删 agentPool.ts + agentId 概念；三路 route（messages/events/stop）合并为 `/api/sessions/:sessionId/run`（SSE 流响应）；history 改 `/api/sessions/:sessionId/history`（直读盘）；URL `/chat/{sessionId}`
- **domain 层**：原则上不改；仅可选一行微调（destroy 也 abort 在途 LLM，使"关连接=真停"语义闭合）
- TUI 不受影响（TUI 直接用 AnyAgent，不经 web agentPool）

## 场景判断
**场景 B（整体替换）**：删 agentPool + agentId + 三路 route，新实现替代。按改进后 rdd：不反推旧 agentPool spec（被删代码反推空转），从新行为派生 spec，旧行为标 superseded。
