# FE-026: 用量面板 + 状态栏性能指标

## Feature（Story 内联）

作为 AnyCode 用户，
我想看到每次调用的 token/费用/缓存命中/速度明细与会话外累计，
以便判断费率、验证缓存是否生效、并为缓存优化提供数据依据。

## 决策（2026-09-16，用户）

- DEC-149：面板范围**含跨会话累计**——新增持久化用量账本（按工作区，~/.anycode/projects/<projectKey>/usage.jsonl），存原始 token 数，费用按显示时点的 pricing 换算（单价改了历史账单跟着修正）。
- DEC-150：TTFT/tok/s 显示**最新一次调用值**（状态栏每轮刷新），逐轮明细入 Usage 事件与面板可回看。
- DEC-151：`cached_tokens` **有则显无则隐**——provider 未报（部分 OpenAI 兼容层无 prompt_tokens_details）不显示命中率，不造假数据。

## 交付边界

- 数据链：llm.ts 捕获 cached_tokens/ttft/duration → Usage 事件扩展（可选字段，向后兼容）→ server 侧账本落盘 → web StatusBar 实时指标 + 用量面板。
- 账本只增不改；不做配额/预算告警（后续条目）。
