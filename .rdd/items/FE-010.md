# Feature: Web slash 指令

## 现状（Impact）
- Web 输入框只支持普通文本提交，无 "/" 指令（对齐主流 chat UX 的 slash command）

## Stories（Lite 内联）
- US-A 触发：输入框首字符 "/" → 弹出指令列表（模糊匹配补全）
- US-B 内置指令：/clear /new /model /help 等（范围待决）
- US-C 自定义指令：从 .anycode/commands/ 加载用户自定义指令（待决）
- US-D 执行：选中指令执行对应动作（清空/新建/切模型等），非当对话消息

## Open Questions（全已决策 → DEC-037..040，见 SPEC-010）
- Q-1 内置范围 → 更多内置（/clear /new /help /config /model /sessions）(DEC-037)
- Q-2 自定义 → .anycode/commands/*.md（body 作 prompt 模板）(DEC-038)
- Q-3 与 @file → 可同输入（/cmd @file）(DEC-039)
- Q-4 反馈 → 行内 System 事件 (DEC-040)

## 实现记录
- web：
  - `app/api/workspaces/[projectKey]/commands/route.ts`：GET 扫 .anycode/commands/*.md → [{name, body}]
  - `app/api/workspaces/[projectKey]/config/route.ts` 加 PATCH：{default} 服务端切默认 provider（保留 apiKey 原值）
  - `hooks/useAgent.ts`：加 clear()（清 events）+ appendSystem(msg)（插本地 System 事件）
  - `components/ChatView.tsx`：输入 / 开头 → 指令 popover（内置+自定义模糊补全，↑↓高亮，Tab/Enter 执行，Esc 清）；内置 /clear /new /help /config /model（显/切）/sessions；自定义 body 作 user 消息提交；未知指令 System 反馈；router.push 跳转
  - ChatView.test 更新 useAgent mock（clear/appendSystem）+ mock useRouter
- 验证：web tsc 干净（除既有 providers jest-dom 错）+ 53/54 无新回归
- deferred：自定义指令 frontmatter 元数据、/model 切换确认、指令补全排序
