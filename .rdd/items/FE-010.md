# Feature: Web slash 指令

## 现状（Impact）
- Web 输入框只支持普通文本提交，无 "/" 指令（对齐主流 chat UX 的 slash command）

## Stories（Lite 内联）
- US-A 触发：输入框首字符 "/" → 弹出指令列表（模糊匹配补全）
- US-B 内置指令：/clear /new /model /help 等（范围待决）
- US-C 自定义指令：从 .anycode/commands/ 加载用户自定义指令（待决）
- US-D 执行：选中指令执行对应动作（清空/新建/切模型等），非当对话消息

## Open Questions（blocking，待批量决）
- Q-1 内置指令范围：哪些内置（/clear /new /model /help /config?）
- Q-2 自定义指令：支持 .anycode/commands/*.md？格式（前置 frontmatter + 模板）？
- Q-3 指令与 @file 关系：指令可带参数？@file 与 / 可同用？
- Q-4 执行反馈：指令执行结果如何展示（toast / 系统 message / 行内）？
