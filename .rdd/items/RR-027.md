# RR: 后台运行与多 agent 并行（切换会话不停止运行）

## 原始需求

> 之前我们说过，切换会话停止 agent 运行，但是这造成了一个功能的缺失：多 Agent 多项目并行使用。所以我们还是需要做到切换会话不停止 AI 运行，关闭软件才停止运行。

> 在体验上，还可以在 sessions 左侧菜单 session 的名称右侧显示 session 的状态。

## 业务目标

- 切走会话 / 关闭标签页不再中止运行中的任务；只有关闭软件（server 进程退出）才全部停止。
- 支持多项目、多会话并行运行与并行观察。

## 边界

- 终态语义（FR-14 / SPEC-031）不变；变的只是"谁触发 stop"与"何时 destroy"。
- 同一会话 single-flight（并发提交 409）保持。
- 桌面关窗即退（现状），托盘保活不在本需求内。

## 未确定事项

- 后台会话卡在权限 ask 时：挂起等待还是超时拒绝？（blocking）
- maxConcurrentRuns 缺省值？（非 blocking，有推荐）
- 事件序号与重挂协议的具体形态（技术设计，LLM 定）
