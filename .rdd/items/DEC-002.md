# DEC-002: Memory 介入点 = saveMemory / loadMemory 两函数，不改 agentLoop 主体

## 问题
FE-003 LLM 介入 memory 的改动面有多大？

## 决策
- `saveMemory`（`memory.ts:17`）是唯一写入口，`loadMemory`（`:39`）是唯一读入口
- 调用点仅 `main.ts:234`（写）/ `main.ts:252`（读）两处
- LLM 介入逻辑加在 saveMemory 内或其调用边界，**不改 agentLoop 推理循环主体**
- 唯一例外：若 Q-010 选「memory 工具主动调用」模式，需向 agentLoop 注入 memory 工具（此时才动 core.ts）

## 理由
blast radius 极小，风险可控。先在 saveMemory 边界做，能覆盖「判断 + 摘要」两种模式。
