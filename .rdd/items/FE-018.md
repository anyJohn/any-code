# Feature: ask_question 工具

## 现状（Impact）
- 无 ask/question 工具。`InteractionRequest`/`interaction$` 休眠 scaffold 可复用。toolCall 已有事件流 + signal 中断。run 路由 SSE 单向泵事件。

## Stories（Lite 内联）
- US-A schema：`ask_question(question: string, options?: string[2-4], multiSelect?: bool, header?: string)`。options 给出→用户选（UI 自动加 Other 自由输入）；无 options→纯自由输入；multiSelect 允许多选。
- US-B handler 阻塞：注册 pending（id→{resolve}）到 `pendingInteractions` 单例 Map → 发 INTERACTION 事件（data: id/question/options/multiSelect/header）→ `Promise.race`([answerPromise, abortPromise])：答案 resolve→return 答案串（多选 join ", "）；signal abort→resolve sentinel（不 reject，agentLoop 下轮 STOPPED）。
- US-C 注册表：`pendingInteractions`：register(id, resolve, reject?) / resolve(id, answer) / cancel(id)。module 单例（Next 单进程共享）。
- US-D 事件：`EventType.INTERACTION = "Interaction"`；data {id, question, options?, multiSelect?, header?}。
- US-E web 回答端点：`POST /api/sessions/:sid/interact` body {interactionId, answer} → `pendingInteractions.resolve(id, answer)`。
- US-F web UI：useAgent 收到 Interaction 事件 → 设 pendingInteraction 状态 → ChatView 渲染模态（header/问题 + 选项按钮 + Other 输入 + 多选 toggle + 提交）；提交→POST interact→清 pending。单飞：与 /run 同 session（agent 阻塞中，/run 持有它）。
- US-G 工具分组：allTools + executeTools 含 ask_question（sub-agent 也可问，事件 tagged author+runId）；readOnly 不含。
- US-H systemPrompt 引导：何时该问（genuinely blocked、有 trade-off、非低风险默认）/何时不该问（低风险自己定、危险命令确认走权限层勿用此工具）。

## Open Questions（blocking，待 Human 决 → DEC-109.. 落 SPEC-027）
- Q-1（blocking）单次一问 vs 批量（1-N 问/次）？ → A) 单次一问（MVP 简单，覆盖 90%；需多问 LLM 连调） / B) 批量 1-5（业界三工具都支持，UI 多步模态复杂）。推荐 A。
- Q-2（blocking）无答案超时策略？ → A) 无超时（阻塞到答或 stop；stop 覆盖中止；用户不理则 agent 挂起——可接受） / B) idle 超时→"best judgment" sentinel（业界 hermes/openclaw 同路，更稳）。推荐 B（避免 agent 无限挂起；超时 sentinel 让 LLM 自行定夺）。
- Q-3（非 blocking）工具名 `ask_question`（用户 todo 措辞）？ → 推荐 是。
- Q-4（非 blocking）答案串格式：单选=label、多选=labels join ", "、自由输入=原文？ → 推荐 是（tool_result 直接是答案串，最简）。
- Q-5（非 blocking）sub-agent（plan）能否调 ask_question？ → 推荐 能（executeTools 含；事件 tagged）。
- Q-6（非 blocking）stop 中止时 handler 行为：resolve sentinel（不 reject）让 agentLoop 干净 STOPPED？ → 推荐 是（reject 会变 ERROR，不干净）。
