# Raw Requirement: provider 支持多模型 + /model + /provider 指令

## 来源
用户：一个 provider 支持多个模型，使用 model 指令切换。支持设置 model id、model name。支持 provider 指令切换 provider。

## 业务目标
- config schema：provider 从单一 `model` 改为 `models: [{id, name?}]` + `defaultModel`（当前生效模型 id）
- `/model` 指令：切当前 provider 的模型（`/model` 显当前 + 列模型；`/model <id>` 切 defaultModel）
- `/provider` 指令：切 provider（`/provider` 显当前；`/provider <name>` 切 default）
- model 支持 id（调 API 用的真实模型名）+ name（展示名）
- /settings 编辑 provider 的 models 列表

## 范围
- domain：config schema（models + defaultModel）；callLLM 用 defaultModel；向后兼容旧 `model:` 单值
- web：/api/config 加 model 切换；/model 改切模型 + 新增 /provider 切 provider；/settings 编辑 models；status 显当前模型

- /model 切换范围（当前 provider 内 / 跨 provider）
- /model <arg> 按 id 还是 name
