# RR-030: 用量面板 + 状态栏性能指标

## 业务目标

让 token 消耗、费用、prompt 缓存命中与响应速度**可见**：用户能看到这个 agent 费不费钱、缓存有没有生效、慢在哪。为后续缓存优化（memory 写入去抖等）提供数据依据。

## 现状（已有哪些地基）

- Usage 事件（durable）：prompt_tokens / completion_tokens / contextWindow / model 戳
- StatusBar：会话累计 token + 费用换算（config pricing 段，FR-22 ModelPricing 已就位）
- llm.ts：流式 include_usage 已开；Anthropic 适配层已有

## 缺口

- `cached_tokens`（`prompt_tokens_details.cached_tokens`）未捕获 → 缓存命中率无从计算
- TTFT（首字延迟）/ 生成速度（tok/s）无采集
- 用量只有状态栏一行累计，无面板（逐轮明细 / 按模型分布 / 命中率趋势）

## 未确定事项

- 指标口径（per-call vs per-回合聚合）、面板范围（会话级 vs 跨会话累计）、缓存字段缺失时的降级显示
