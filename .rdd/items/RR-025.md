# RR: 内置能力体系（abilities）—— 内置 skill + 内置 mcp 注册器 + 开关 + 四层技能 + 目录注入 + AGENTS.md 规则

## 需求来源与背景

- feature-list（Skill 段）：内置技能（todo）、兼容 `.agents/` 技能（todo）；Rule 段：AGENTS.md 规则（todo）。
- `内联应用探索.md`：6 条探索（.agents/skills、AGENTS.md、摘要注入、内置可开关不可删、内置 skill+mcp 统一展示）。
- 多轮设计收敛 + 主流开源 harness（opencode/deepseek-harness/openclaw/pi/hermes）源码调研 + Claude Code 官方机制调研（详见对话记录与 commit body）。

## 业务目标

把内置能力做成产品级一等公民：**随包分发的内置 skill 与内置 mcp（连接器）收敛为统一的"能力"（ability），可开关、不可删除**；用户技能扩展保持四层来源（项目 > 全局 > .agents > 内置）与业界一致；技能注入从"全量拼 prompt"转为"目录常驻 + 按需取全文"（token 友好）；规则系统从 `.anycode/rules/` 多文件退役为 AGENTS.md 文件（additive）。

## 关键决策（Human 已确认，冻结）

| # | 决策 | 值 |
|---|---|---|
| D-1 | 统一"内置能力"命名空间 | 内置 skill + 内置 mcp 收敛为 ability；对外统一展示（类似 hermes 浏览器/搜索） |
| D-2 | 能力注册器 | `registerAbility({name, kind:"skill"/"mcp", ...})`；内置不可删，只可开关；注册器内同名 fail-fast throw（抄 deepseek） |
| D-3 | abilities 配置 | `abilities: { <name>: { enabled: true/false } }`；**未配置=不启用**；随包默认 config.yaml 预置开启；`reloadConfig()` 热生效 |
| D-4 | 层优先级 | 项目(`.anycode/skills`) > 全局(`~/.anycode/skills`) > `.agents`(`~/.agents/skills`，HOME 级) > 内置；同名后层覆盖 + warning（抄 opencode） |
| D-5 | 摘要注入 | 目录（name+description）常驻 system prompt + `skill` 工具按需取全文（hermes 式渐进披露） |
| D-6 | 规则退役 | 删 `.anycode/rules/` 多文件；规则 = AGENTS.md：全局 `~/.anycode/AGENTS.md` + 项目 `workspaceDir/AGENTS.md` + `.agents/AGENTS.md`，additive 注入；**破坏性变更，不兼容**（产品无用户） |
| D-7 | MCP 合并 | 内置连接器（kind:mcp ability）并入连接集；`enabled:false` 保留定义、运行时剔除；同名**整条覆盖**（非字段级 merge，弃 opencode mergeDeep 教训） |
| D-8 | 内置连接器形态 | bundled 自包含 stdio MCP server（`@modelcontextprotocol/sdk`），完全复用 `mcp.ts` 现有 stdio 传输，离线自包含 |
| D-9 | **Q-1：v1 三件全注册** | web-fetch / web-search = 真 bundled MCP 连接器（fetch_url/search）；browser-use = skill 编排（编排前两者，浏览器-lite 操作模型）。真 CDP 浏览器（desktop 内嵌 offscreen window / 用户浏览器 CDP / opt-in playwright）为 v2 路线，不阻塞 v1 |
| D-10 | **Q-1 扩展：abilities 条目支持 `config` 字段** | `web-search: { enabled: true, config: { provider: ddg, apiKey: "" } }`（provider 可插拔：ddg 无 key 默认 / tavily 或 bing 配 key） |

## 范围

- domain 内核：`abilities.ts`（注册器+开关解析）+ `builtin.ts`（注册）+ `config.ts`（abilities 解析）+ `skill.ts`（四层+目录注入+skill 工具）+ `rule.ts`（AGENTS.md）+ `mcp.ts`（合并+开关）。
- web：Settings"内置能力"开关面板。
- 默认 `config.example.yaml` 与默认配置预置 abilities。

## 已排除（明确不做）

- 不做纯 seed 模式（hermes hand-off；本 RR 选注册器不可删）；不做 MCP 字段级深合并；不做多文件规则兼容读取；不做内置能力"升级 hash 追踪"（hermes manifest）——留作远期。
