# Raw Requirement: skills/rules/MCP 两层（Global + Project），web 只配 Global

## 来源
用户：skills/memory/rules/MCP 也支持 Global + Project 级别；但 Web 页面的配置只支持配置 Global，用户可以自己在 workspace 目录中添加项目级，简化 web 设置。

## 业务目标
- skills/memory/rules/MCP 都支持 Global（~/.anycode/）+ Project（<workspace>/.anycode/）两层，合并加载
- web /settings 只编辑 Global（~/.anycode/config.yaml 的 providers + mcp），不碰项目级
- 项目级（skills/rules/memory/MCP）由用户自己在 <workspace>/.anycode/ 加文件，无 web UI
- memory 已是两层（无需改）；skills/rules 加全局层；MCP 加项目层 + 合并

## 范围
- domain：loadSkills/loadRule 合并全局+项目；loadMcpTools 合并全局 config.mcp + 项目 mcp 文件
- web：/settings 不变（仅全局）；status 面板 skill 数可反映合并（后续）
- 项目级文件：用户手动加，无 web 编辑 UI

## 现状
- memory：已两层（global ~/.anycode/memory.md + project .anycode/memory.md，loadMemory 合并）✓
- skills：仅 project .anycode/skills/（loadSkills 读项目）→ 加全局层
