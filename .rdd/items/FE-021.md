# Feature: 事件系统重构（typed 可序列化 union + durable 事件日志作 reload 真值）

## 现状（根因）
- `AgentEvent { timestamp, type:EventType, message, data?:any, author?, runId?, turnId? }`（`domain/src/type.ts`）；`EventType` 16 值枚举。
- `EventStream` per-agent in-memory（`eventStream.ts`），`submit(payload)` 盖 timestamp 推 `event$`/`history$`。
- `core.ts:79` 每回合 `turnId=randomUUID()` 盖 Iteration/Assistant/Thinking/Tool，**不落盘** → reload 丢失。
- reload 双源：`messages`（ChatMessage JSONL，LLM 真值）+ `events`（仅 durable=Error 持久）；web `messagesToEvents` 从 messages 反推 + `mergeEvents` 内容匹配塞回 Error。
- 三痛点：① error shape 分叉（domain 抛 raw Error，adapter replacer 序列化）② 定位 hack（`mergeEvents` 靠 `Error executing task:` 前缀）③ 重建有损（deltas/usage/progress 丢）。
- latent bug：`core.ts:70` 压缩失败发 `Error`（非终态），但 web `TERMINAL={Done,Error,Stopped}` 把所有 Error 当终态 → 压缩失败误终止 run。
- 两处 ERROR emit：`main.ts:291`（终态任务错误，`data:err`）+ `core.ts:70`（非终态压缩失败，无 data）。
- 18 个 `eventStream.submit` 站点：main.ts×5、core.ts×8、toolCall.ts×3、askQuestion.ts×1、agent.ts（sub-agent proxy）。

## 范围（Feature，分阶段）
- **P1**：`ErrorPayload`+`serializeError`；终态 `Error`/非终态 `Warning` 拆分；domain 发 `data:serializeError(err)`（plain）；server 删 replacer/serializeEvent；web 加 Warning 渲染、TERMINAL 去误终止。
- **P2**：扩 `DURABLE_TYPES`；持久化 durable 事件日志（server /run `appendEvent`，e 已可序列化无转换）；`/history` 返回 events 全集；web reload 重放 `data.events`，删 `messagesToEvents`+`mergeEvents`。
- **P3**：`AgentEvent` → discriminated union（per-variant typed payload，删 `data?:any`）；18 emit 站点迁 variant 字段；web `AgentEvent` 镜像 union。
- **P4（可选远期，另立）**：pi 风格 `AgentMessage`+`convertToLlm` 过滤；`beforeToolCall`/`afterToolCall` hook（权限拦截）。

## Open Questions（blocking，待 Human 决策）

- **Q-026 Tool result 双存**：durable Tool event 持久 result —— (a) 全量 result（无 UX 回归、存储+）vs (b) result 预览（reloaded 结果截断、省存储）？推荐 (a) 全量（正确性优先，监控 JSONL 后酌情转 b）。
